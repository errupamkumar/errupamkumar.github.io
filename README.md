# Rupam Kumar · Portfolio (errupamkumar.github.io)

Personal portfolio of **Rupam Kumar**: Power BI Developer, BI Engineer at HCLTech and Claude Certified Architect.

🌐 **Live:** https://errupamkumar.github.io/

A single-page static site (HTML, CSS and vanilla JS, no build step) that tells my career as a journey across the world, from Patna to Bikaner to Noida to Dublin:

- An interactive canvas dot-globe that traces the journey with animated arcs (drag to spin)
- A scroll-drawn route through five career stops
- An animated, illustrative fraud-analytics dashboard case study
- Filterable certifications with live verification links (Microsoft Learn, Credly)

```
index.html
assets/css/style.css
assets/js/main.js      # interactions, globe, certifications data
assets/js/land.js      # land-dot coordinates for the globe (from Natural Earth via world-atlas)
assets/img/
```

To edit certifications, update the `certs` array in `assets/js/main.js`.
